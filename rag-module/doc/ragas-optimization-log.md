## 迭代 1：收紧回答契约（生成层）

### 改动理由

先处理“证据已完整但回答仍低分”的生成层问题，以便与下一轮检索改动分开归因。共享回答 Prompt 将要求：第一句直接回答；逐项覆盖问题中的子问题；简单事实题控制在 1–3 句；只在问题要求总结时展开；禁止添加材料未明确支持或用户未要求的应用场景、建议、因果解释和背景；证据不足时只指出确切缺口，不用无关片段凑答案。

实现内容：

- 在共享 `answer_contract` 中加入直接回答、逐项覆盖、简单事实题 1–3 句、证据边界和精确拒答约束。
- 在通用 system prompt 中禁止擅自添加应用场景、临床建议、因果解释或材料外取舍标准。
- 增加 Prompt 注册与注入测试，确保所有回答模式都携带同一回答契约。

修改后已重新启动后端，再运行同一 30 条评测集。

### 结果分析

1. **生成层改动有效。** 第 7 条删除了材料外的临床应用建议，Faithfulness 从 0.5556 升至 1.0000，Answer Correctness 从 0.6907 升至 0.9335。新增事实题、模糊/对抗题和长综合题的 Answer Correctness 分别提升 0.2520、0.1396 和 0.1372。
2. **检索结果本轮没有因 Prompt 改动而改变。** 新增多跳组三题的 Context Precision/Recall 均值仍分别为 0.5852/0.5833。第 24 条 Recall 仍为 0.5；第 25 条仍只有 nnU-Net 和少量 Attention U-Net 证据，Recall 仅 0.25，模型因此正确说明证据不完整，但 Answer Relevancy 被记为 0。
3. **Answer Relevancy 的总体下降需要分开解释。** 其主要降幅来自证据不全的第 24、25 条，以及正确拒答仍固定为 0 的三条文档外问题；旧有 15 条样本的 Relevancy 反而从 0.8273 小幅升至 0.8318。不能通过要求模型在缺证据时猜测来修复，应转向检索覆盖率。
4. **下一轮归因指向检索层。** 固定每路 Top-K=10、最终 Top-N=5 的预算无法适配“三类任务”“三篇论文”与长流程总结。下一轮将只对可识别的综合问题扩大候选和最终证据预算；跨论文问题还将限制单文档占位，避免同一论文垄断上下文。普通事实题维持原预算，以控制 Precision 和上下文长度。

## 迭代 2：按查询范围自适应证据预算（检索层）

### 改动理由

检索诊断显示第 25 条的最终 5 条证据中，前三条均来自 nnU-Net，随后才是 Attention U-Net，原始 U-Net 完全缺席；BGE 前后的前 10 个候选也主要被前两篇论文占据。问题并非回答模型不知道如何综合，而是固定 Top-K/Top-N 在进入回答阶段前就丢失了第三篇论文。

本轮将综合问题的每路召回从 10 扩到 20、最终 parent 证据从 5 扩到 8；仅对问题中明确出现“多篇论文/文献”的跨文档问题，在首轮选择中限制每篇文档最多 3 条，剩余名额再按原排序补足。规则同时识别“三类任务”和“概括/完整流程”等综合提问；普通事实题继续使用原预算。这样既提高多跳覆盖率，也避免对所有查询全局扩大上下文而损害 Precision。

实现时的定向诊断还发现：单纯扩大预算会让无关的第三篇论文进入结果，而显式点名的原始 U-Net 仍可能缺席。因此又加入通用的文档标题匹配与定向补召回：按标题中的方法名识别问题点名的文档，长名称优先匹配，避免 `Attention U-Net` 和 `nnU-Net` 被再次误判为普通 `U-Net`；每篇目标文档以去掉文档名后的主题查询执行 BM25 补召回，并优先保留前两条词面证据。该逻辑不硬编码本评测集论文名，也遵守当前用户可读文档和已发布版本快照。

修改后重新启动后端。检索诊断确认第 25 条的最终上下文同时出现：

- U-Net 的 overlap-tile、镜像补边和大 tile/单图 batch；
- Attention U-Net 因图像大小和硬件内存限制重采样到 2.00 mm；
- nnU-Net 的显存估算、patch/batch 自适应和级联策略。

### 结果分析

1. **检索层目标达成。** 四项总体指标改善，尤其 Recall 与跨文档 Relevancy 的增幅直接对应定向诊断中的缺证据问题；普通题仍保持 5 条上下文。
2. **Answer Correctness 的 -0.000251 可视为持平。** 第二轮与第一轮使用相同 Prompt，但普通题答案措辞和长度仍有明显随机波动；例如第 5 条在相同 5 条上下文下从约 230 字扩展到 500 余字，Correctness 从 0.9524 波动到 0.5331。相反，四道流程/综合题的 Correctness 均值从 0.7807 升到 0.9054。该变化不能归因于检索退化。
3. **下一轮应控制生成随机性。** 当前默认回答温度为 0.7，而查询改写和意图识别已使用 0。科研事实问答更重视可复现性和严格证据边界；下一轮将为 RAG 回答设置独立低温选项，并同时作用于在线 RAG 与 Dataset 生成，减少同一证据下的冗长和正确性抖动。
